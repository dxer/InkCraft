五大核心模块，贯通创作全流程

从灵感采集、知识消化，到切角策划、文风克隆与全渠道分发。

原子永久知识卡片 (`/cards`)

践行卢曼卡片盒笔记法。每张卡片固化断言命题 (Claim)、底层推导 (Mechanism)、适用边界与潜在概念线索 (Connection Hints)。

支持瀑布流、紧凑清单与力导向关联图谱

智能选题雷达 (`/topics`)

通盘研判卡片知识簇。内置反差冲突 (Paradox)、跨界同构 (Intersection) 与专题纵深 (Deep Dive) 碰撞，产出 3 选 1 标题与结构化大纲。

支持意图检索、排除已读与随机灵感抽样

沉浸工坊与文风派生 (`/workshop`)

双栏原料工作台一边查卡片一边写母稿。录入样稿自动克隆语气语感，一键派生为微信公众号（精美内联样式）、小红书、知乎等平台。

微信推文一键复制 · 完美内联排版

9 大开放 MCP 协议 (`/mcp`)

支持 SSE 与 Direct JSON-RPC 双模协议。为 Claude Desktop、Cursor、智能体提供卡片意图检索、网状关联发现与原始母档双向穿透。

墨匠剪藏 · InkCraft Clipper

Chrome 与 Edge 浏览器的轻量灵感采集利器。

01. 下载产物

在 GitHub Release 或 Actions 页面直接下载 inkcraft-clipper.zip（解压模式）或 inkcraft-clipper.crx。

02. 载入浏览器

打开 chrome://extensions 开启开发者模式，点击「加载已解压的扩展程序」选择解压目录。

03. 一键同步

填入你的墨匠服务端地址（如 http://localhost:3000），即可实现浏览时随手一键剪藏。

方案 A：Docker Compose 生产部署（推荐）

官方预编译

拉取轻量镜像（~180MB），数据自动持久化到同级 ./data 目录：

# 1. 克隆代码
git clone https://github.com/dxer/InkCraft.git && cd InkCraft

# 2. 启动容器
docker compose up -d

# 3. 查看容器状态
docker compose ps

Node.js >= 20

pnpm dev       # 访问 http://localhost:3000
