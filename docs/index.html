常见问题解答 (FAQ)

关于数据隐私、大模型接入与工作流协同。

我的笔记与卡片数据存储在哪里？安全吗？

所有知识库、卡片盒与创作母稿全部存储在本地 SQLite 数据库（Docker 部署时挂载在宿主机 ./data/inkcraft.sqlite）。墨匠不上传任何数据到第三方云端，您的知识资产 100% 私有可控。

支持接入哪些大模型（LLM）？

支持所有遵循 OpenAI 兼容规范的模型接口！您可以在系统设置中自由绑定 DeepSeek、Claude、OpenAI、Kimi、通义千问，或使用本地 Ollama 运行开源模型（如 Qwen2.5、Llama 3 等）。

什么是 MCP 协议？我该如何用它连接 Claude Desktop？

MCP (Model Context Protocol) 是 Anthropic 制定的标准化上下文连接协议。墨匠内置了 9 大只读 Tools。在系统设置中生成 API Key 后，将 JSON 配置粘贴进 Claude Desktop 或 Cursor，大模型即可直接在对话中检索你的卡片库和选题。
