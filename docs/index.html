常见问题解答 (FAQ)

零门槛答疑，打消你的所有顾虑。

我的文章和数据安全吗？会不会被泄露？

100% 本地安全！墨匠采用“本地优先”架构，所有剪藏、卡片、选题和母稿都保存在你本地电脑的 SQLite 文件中（./data/inkcraft.sqlite）。墨匠没有云端服务器收集数据，你的隐私完全掌握在自己手里。

需要花钱买大模型 API 吗？可以用免费/本地模型吗？

支持绑定任意兼容 OpenAI 接口的模型！你既可以使用极具性价比的 DeepSeek、Kimi、Claude、OpenAI，也可以用 Ollama 本地完全免费运行开源模型（如 Qwen2.5、Llama 3 等），不花一分钱也能跑起来。

什么是 MCP 协议？我必须用它吗？

不用也不影响你在墨匠网页里写作！MCP 是给喜欢用 Claude Desktop 或 Cursor 写文章的用户准备的高级“外挂接口”——开启后，你在 Claude 窗口聊天时，它就能直接调取你在墨匠里存好的所有卡片和灵感。
